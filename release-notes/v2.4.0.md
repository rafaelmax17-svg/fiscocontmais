# FiscoCont+ 2.4.0

## Correções

- **Corretor do SPED Fiscal · Validação do PVA: "Código de barras inválido" (0200, campo 04).** O Corretor passa a limpar, sozinho, o código de barras que não é válido:
  - o próprio código interno do produto, como 00027037;
  - número inventado ou com o dígito verificador errado.

  O campo só aceita GTIN-8, 12, 13 ou 14 válido e só deve ser preenchido quando o produto tem código de barras. O código de barras válido continua como está. O mesmo vale para o fator de conversão (0220).
- **Baixas DF-e · Saídas (RO):**
  - Depois do código, o sistema espera o arquivo terminar de chegar. Arquivos grandes não dão mais "tempo esgotado" no meio do download, e a tela mostra quantos MB já chegaram.
  - Se a SEFIN demorar para montar o arquivo, o sistema espera até 3 minutos.
  - Se o site abrir o arquivo na tela em vez de baixar, o sistema baixa assim mesmo.
  - O pedido do mês já usado antes é procurado primeiro, com menos telas abertas.
  - O aviso de parte que falta ficou mais claro: mostra quantas partes faltam e que a outra já está na pasta.
