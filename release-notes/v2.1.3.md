# FiscoCont+ 2.1.3

## Atualização automática

- O sistema agora procura versão nova a cada 30 minutos, mesmo que fique aberto o dia todo. Antes, ele só procurava quando era aberto.
- Quando a versão nova estiver pronta, aparece o aviso "Reiniciar e atualizar". Se preferir terminar o que está fazendo, é só fechar o aviso: a atualização entra sozinha na próxima vez que você fechar o sistema.
