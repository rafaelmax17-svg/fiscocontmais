# FiscoCont+ 2.1.0

## Segurança · login individual

- **Cada pessoa tem o seu usuário.** O acesso agora é por e-mail e senha próprios, e não mais por uma senha dividida entre todos.
- **Trava por inatividade:** se o sistema ficar parado por um tempo, a tela trava e pede a senha de novo. Nada do que estava aberto se perde.
- **Salvar meus dados:** na tela de entrada, marque "Salvar meus dados neste computador" para o sistema já trazer o e-mail e a senha nas próximas vezes. Os dados ficam guardados de forma protegida, só para o seu usuário do Windows. Para apagar, é só desmarcar a opção.
- **Só abre com internet:** por segurança, o sistema não inicia sem conexão com a internet. Se a conexão cair no meio do uso, o trabalho continua; a internet é exigida para entrar.
- Depois de 5 senhas erradas seguidas, o sistema espera um tempo antes de deixar tentar de novo.
