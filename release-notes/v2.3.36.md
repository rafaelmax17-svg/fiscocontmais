# FiscoCont+ 2.3.36

## Correções

- **Baixas DF-e · NF-e e NFC-e Saídas (RO):** o download do DFe-Download da SEFIN voltou a funcionar. Antes, depois de digitar o código da imagem, a janela ficava aberta e o arquivo não vinha.

## Novidades

- **Baixas DF-e · Saídas (RO): a página da SEFIN não aparece mais.** O sistema entra com o certificado da empresa e procura o pedido do mês sem mostrar o site.
  - Só a imagem do código aparece numa janela do FiscoCont+. Digite e aperte Enter ou Enviar.
  - Se a SEFIN não aceitar o código, aparece uma imagem nova para digitar de novo.
  - **Pedido com mais de um arquivo (Parte 1, Parte 2…):** todas as partes são baixadas, uma de cada vez, e as notas são juntadas na mesma pasta.
  - "Pular esta parte" deixa aquela parte para depois: ela fica como "falta digitar o código" e é baixada no próximo "Baixar notas". O ✕ para a busca das saídas.
  - A página da SEFIN só aparece quando é preciso fazer uma Nova Solicitação, para você conferir e confirmar o pedido.
