# FiscoCont+ 2.0.0

## Tela de abertura

- **A tela de abertura agora aparece por inteiro.** Antes, a janela surgia vazia enquanto carregava e, em computadores mais lentos, a animação começava quase na hora de fechar. Agora a tela só aparece depois de desenhada, fica no mínimo 4,8 segundos (a animação do gráfico termina e dá para ver a tela completa) e o sistema só começa a carregar depois que ela está na tela, para não disputar o computador com a animação.
- **Saída suave:** a tela de abertura some com um esmaecimento e o sistema aparece logo em seguida.
- Se o sistema demorar mais para carregar, a tela de abertura continua até ele estar pronto.
