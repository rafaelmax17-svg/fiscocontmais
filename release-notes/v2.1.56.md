# FiscoCont+ 2.1.56

- **Dashboard (SPED) · saldo credor:** quando a empresa tem saldo credor do mês anterior, ele aparece na Apuração do ICMS, logo acima do ICMS a recolher.
- Quando o mês fecha com saldo credor, aparece um quadro com o valor que vai para o próximo mês e uma barra mostrando quanto dos créditos abateu os débitos e quanto sobrou.
- O relatório do Dashboard (que vai para o cliente) não mostra mais os nomes dos registros do SPED, só a descrição de cada valor.
