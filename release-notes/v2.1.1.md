# FiscoCont+ 2.1.1

## Usuários e senhas

- **Crie a sua senha:** no primeiro acesso, entre com a senha provisória que você recebeu. O sistema pede para você criar a sua própria senha (pelo menos 8 caracteres, com letras e números) e confirmar.
- **Esqueceu a senha?** É só falar com o Admin do sistema: ele gera uma senha provisória nova para você, e no próximo acesso você cria a sua de novo.
- O menu mostra só os módulos liberados para o seu usuário.
