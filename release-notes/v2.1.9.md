# FiscoCont+ 2.1.9

## EFD-Contribuições · Conferência da redução linear (LC 224/2025)

- No painel de conferência da EFD-Contribuições há uma nova parte, só para o escritório, que confere a redução linear de benefícios de PIS/COFINS:
  - se o período já está alcançado (a partir de 01/04/2026);
  - se o ajuste está no M220/M620 com código 11, como acréscimo, e com a alíquota certa (0,165% e 0,76% no não cumulativo; 0,065% e 0,30% no cumulativo);
  - se toda nota com alíquota zero (CST 06) tem o detalhamento no M225/M625, com a base, o valor e a conta contábil corretos;
  - se o monofásico (CST 04) ficou de fora, e se as notas trazem a menção à lei no C110.
- Mostra também a lista nota a nota, com a base, o PIS e a COFINS de cada uma.
- Essa conferência **não vai para o relatório do cliente**.
